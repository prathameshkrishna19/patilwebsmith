Project Overview

A visually appealing portfolio website for an interior design studio. Showcases high-quality project galleries, design philosophy, client testimonials, and design services to highlight the studio's creativity and expertise.


Key Features


✅ Beautiful image galleries with lightbox
✅ Project categories & filtering
✅ Before & after project showcase
✅ Client testimonials section
✅ Design services page
✅ Contact form for consultations
✅ Responsive design for all devices
✅ Smooth CSS3 animations

Challenges & Solutions


Challenge: Displaying large portfolio images without slowing the website.
Solution: Optimized images and implemented lightbox for faster loading and better UX.
Challenge: Allowing users to filter projects by category.
Solution: Added interactive filtering and sorting functionality for easy navigation.
